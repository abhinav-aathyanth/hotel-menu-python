# Python Test Project

A small Python workspace for testing and learning.

## Files

- `calculator.py` - basic calculator utilities or examples.
- `fetch_table_records.py` - data retrieval from a table or database.
- `mysql_sample.py` - sample MySQL database interaction.
- `pokemon.py` - example script related to Pokémon data or logic.
- `Untitled-1.py` - miscellaneous or scratch Python code.

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv .venv
   ```
2. Activate the virtual environment:
   - Windows PowerShell:
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
   - macOS / Linux:
     ```bash
     source .venv/bin/activate
     ```
3. Install dependencies if needed.

## Notes

- `.env` is ignored by Git via `.gitignore`.
- Use the virtual environment for package installation and running scripts.

## Usage

Run any script with:

```bash
python <script_name>.py
```
